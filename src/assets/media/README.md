# Медиафайлы

Положите сюда файлы с такими именами (расширение любое из перечисленных):

| Имя файла                              | Что это               |
| -------------------------------------- | --------------------- |
| `intro.mp4` / `intro.webm`             | Поздравительный ролик |
| `credits.mp4` / `credits.webm`         | Заключительные титры  |
| `screamer-sound.mp3` / `.ogg` / `.wav` | Звук скримера         |

Если какого-то файла нет, будет показана заглушка: плашка вместо ролика,
синтезированный визг вместо звука скримера.

Страницы комикса кладутся в `../pages/` с именами `0.png`, `1.jpg`, `2.png`, …
Порядок определяется номером в имени, количество страниц считается автоматически.

Картинка скримера — `screamer.png`, чтобы заменить её, просто перезапишите файл.
